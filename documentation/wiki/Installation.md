# 🛠️ Installation

LiveSync is a VS Code extension. The simplest way to get it is directly from the VS Code Marketplace.

---

## 📥 Install from VS Code Marketplace

1. Open **VS Code**.
2. Go to **Extensions** (`Ctrl+Shift+X` or `Cmd+Shift+X` on Mac).
3. Search for **LiveSync**.
4. Click **Install**.

[👉 LiveSync on VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=a-gior.livesync)

---

## 🔄 Updating LiveSync

LiveSync updates automatically when installed from the Marketplace. To check manually:

1. Open the **Extensions** view.
2. Search for **LiveSync**.
3. If an update is available, click **Update**.
