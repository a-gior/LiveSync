# LiveSync Wiki

Welcome to the **LiveSync** wiki! This is the official documentation for setting up, configuring, and using the LiveSync extension for VS Code.

## 📌 About LiveSync

LiveSync is a VS Code extension that allows you to **synchronize a local workspace with a remote server over SSH/SFTP**, with real-time difference tracking and conflict detection.

### Key Features

- **Two-way sync** → Upload and download files and folders between local and remote.
- **Conflict detection** → Warns you before overwriting changes on either side.
- **Customizable event handling** → Define what happens on file save, create, delete, move, or open.
- **Tree View** → See the sync state of every file at a glance (Added, Modified, Removed, Conflict).
- **Ignore patterns** → Exclude files and folders using glob patterns.
- **Easy configuration** → Set up via the built-in Configuration Panel or edit `.vscode/livesync.json` directly.
- **Multi-workspace** → Each workspace folder has its own independent config.

## 💡 Getting Started

1. **Install the extension** from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=a-gior.livesync).
2. **Configure your remote connection** using the Configuration Panel or `.vscode/livesync.json`.
3. **Sync your workspace** and start working with live updates between local and remote.
4. Use the **Tree View** and **Explorer commands** to manage file transfers easily.
